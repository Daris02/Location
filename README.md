# LOCATIONABLE - TYPESCRIPT

This app cli is make locationable object and reserve it.
To init project after clone, run `npm install`.

To launch cli:
```bash
npm run start [command] [options]
```

NB:
To show command of the cli run command `node index.js -h`

Basic command:
  - `npm run start things --show`
  to show all things in database you can reserve or already reserved
  - `npm run start things --add [options]`
  to add thing you want in all objects locationable
